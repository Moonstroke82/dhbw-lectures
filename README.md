## Outputs

Each session is written once in Markdown (`<course>/slides/session-NN.md`) and built into two formats:

- **PowerPoint (.pptx)** with speaker notes, for teaching → `build/<course>/` (not published)
- **Web slides on GitHub Pages** for students → `docs/<course>/` (published from the `docs/` folder)

Build: `python tools/build.py` (all sessions) or `python tools/build.py data-management/slides/session-01.md --preview`. Website (landing page and course pages) is generated by `tools/website.py` from `<course>/course.json` and `SESSION_PLAN.md`. Slide format and citation rules: [tools/FORMAT.md](tools/FORMAT.md). The look is defined in `tools/theme.py` (DHBW corporate design colours: red `E2001A`, grey `5C6971`); the official slide template will be applied there later. The build runs on Windows and macOS; `--preview` (PNG export via PowerPoint) is Windows only.

## Files per lecture

- `MODULE.md`: official module description (English translation + German original)
- `SESSION_PLAN.md`: approved session plan and teaching principles
- `STATUS.md`: session tracker, feedback from lecturer and students, decisions and changes (kept private, not in the public repo)
- `slides/`: slide sources, one Markdown file per session

Partner company names (DSKI project) are never stored in this repository; they appear only in the offline PPTX and in the private STATUS.md.
