# Project Data Engineering and Analytics — Module Description

| | |
|---|---|
| **Program** | Data Science and Artificial Intelligence (DSKI), Bachelor, DHBW Mannheim |
| **Module code** | W4DSKI_404 |
| **Semester** | 6 |
| **Hours** | 50 h contact time + 100 h self-study |
| **Assessment** | Project |
| **Prerequisites** | None formally; builds on the modules Data Engineering and Data Analytics |
| **Language** | English |

## Learning outcomes (English translation)

### Subject competence
Students can successfully carry out projects in data engineering and data analysis.

### Methodological competence
Students are able to select the methods and techniques for the project independently, apply them and combine them with project management methods.

### Personal and social competence
Students can justify and defend their own position and contribution to the project with arguments, and act responsibly and goal-oriented, on their own and in the team. They can reflect on their own role and the roles of others in order to improve cooperation. They understand the different interests of project stakeholders and can take them into account.

### Overarching competence
Students understand the overarching relationships and processes in a project and can assess them.

## Content

In a project team, a topic-specific selection of methods and skills is applied, for example:

- Methods of data engineering
- Methods of data analysis
- Methods of team building
- Methods of project management
- Methods of process analysis and modelling
- Methods of software engineering (analysis, design, test, integration) with implementation in a common programming language

The project builds on content of earlier modules, especially Data Engineering and Data Analytics.

## Organisation (agreed 2026-10-07)

- **Two partner companies, two projects.** The course splits into two project teams, one per company.
- **Head start in semester 5:** the companies introduce their projects in the first session of *Data Analytics*, so teams can form and start preparing during semester 5.
- **Semester 6 is implementation only.** Plenary meetings (about 10 h): kickoff, mid-term presentation, final presentation. No lectures in between. The remaining ~40 h are independent team work that teams plan themselves.
- Company names and project details appear only in the offline slides (PPTX), never on the public website.

## Literature

Current literature on the project topics is provided by the lecturer or researched by the students as part of their projects.

## Open questions

- Agreements with the partner companies: data access, confidentiality / NDA, intellectual property of results, where code is hosted
- First run (year) and dates for kickoff, mid-term and final presentation
